# VectorCraft-Py 矢量图形编辑系统

VectorCraft-Py 是一个用于计算机图形学上机大作业的 Python 桌面绘图应用。程序使用 Tkinter 构建界面，使用 Pillow 作为像素缓冲区，并在代码中自行实现直线、椭圆、多边形填充、贝塞尔采样、线段裁剪和基础几何变换。

项目支持传统矢量绘图、文本生成流程图、图形学算法可视化和操作回放，适合课堂展示与答辩演示。

## 运行

```bash
pip install -r requirements.txt
python main.py
```

如果本机已经安装 Pillow，可以直接运行：

```bash
python main.py
```

## 已实现功能

- 基础图元：矩形、圆角矩形、椭圆、菱形、三角形、直线、箭头、文本。
- 三维讲解图元：正方体、长方体、球体、三维坐标系，适合几何题板书和答辩演示。
- 画笔图元：可自由涂写、圈画和标注，支持颜色和粗细调整。
- 复杂图元：流程图、组织结构图、电路图常用图元。
- 编辑能力：选择、框选、多选、移动、复制、粘贴、删除、置顶、置底。
- 几何变换：平移、旋转、缩放、水平镜像、垂直镜像。
- 裁剪算法：Cohen-Sutherland 线段裁剪。
- 连接线：支持直线、折线、曲线连接，图形移动后自动跟随。
- 辅助功能：网格显示、网格吸附、对齐、等间距分布。
- 历史记录：撤销、重做。
- 文件能力：保存/打开 `.vcraft.json`，导出 PNG 和 SVG。
- 内置模板：流程图、组织结构图、简单 LED 电路图。

## 创新功能

### 1. 文本生成流程图

点击顶部第二行工具栏的「文本生成」，输入箭头式流程描述，程序会自动识别节点、判断分支、连接关系，并生成完整流程图。

示例输入：

```text
开始 -> 接收原始数据 -> 数据完整?
是 -> 清洗与标准化 -> 生成统计图表 -> 保存处理记录 -> 结束
否 -> 生成错误清单 -> 通知用户补充数据 -> 异常结束
```

支持的连接写法包括 `->`、`-->`、`=>`、`→`、`⇒`。判断节点后可以用 `是` / `否` 或 `yes` / `no` 描述分支。

### 2. 图形学算法演示

点击「算法演示」可打开独立演示窗口。窗口左侧逐帧播放算法过程，右侧显示算法说明，包括核心思想、当前帧含义、关键步骤、公式、复杂度和在本项目中的用途。

当前支持的算法演示：

- Bresenham 直线：展示整数误差项如何决定下一个像素。
- DDA 直线：展示浮点坐标累加与像素取整过程。
- 中点画圆：展示八分对称和中点判别式。
- 扫描线填充：展示多边形交点配对和逐行填充。
- Cohen-Sutherland 裁剪：展示区域码、快速接受/拒绝和边界求交。
- 贝塞尔曲线采样：展示控制点和参数采样生成曲线。

演示窗口支持播放/暂停、上一步、下一步、重置，适合答辩时说明底层算法实现。

### 3. 操作回放时间轴

程序会记录关键编辑步骤，例如绘制图形、移动图形、修改属性、生成流程图、删除、粘贴、对齐和等距分布等。

点击「操作回放」可打开回放窗口，使用播放按钮或时间轴滑块查看创作过程。这个功能可以展示作品从空白画布到完整图表的形成过程。回放窗口还提供「导出 GIF」，把整个创作过程保存为动图，便于答辩展示或写进报告。

### 4. 三维几何辅助绘图

左侧「三维」工具组提供正方体、长方体、球体和三维坐标系。图元支持拖拽绘制、移动、旋转、改色、保存工程，并可导出 PNG/SVG，便于讲解空间几何中的棱、面、球和坐标轴关系。

当三维图元放在三维坐标系内部时，程序会自动给顶点或球心标注三维坐标。

### 5. 画笔标注与智能形状识别

左侧「画笔」工具可直接在画布上手写或涂画，适合批注、圈重点和临时标记。右上方可调整画笔颜色和粗细。

打开顶部工具栏的「智能识别」复选框后，画笔轨迹结束时会自动调用形状识别算法（基于重采样 + Douglas–Peucker 简化 + 顶点位置分析），把潦草的涂鸦自动归正为矩形、圆/椭圆、三角形、菱形或直线。识别结果会替换原始画笔笔迹，常用于课堂上「随手一画自动变工整图形」的演示效果。

### 6. UML 类图 / 甘特图 / 时序图模板

在顶部工具栏「模板与演示」一栏新增三个工程类模板：

- **UML 类图**：展示 Shape、Style、Document、Page、History、Renderer 等核心类的属性、方法、聚合/组合/依赖关系，适合答辩讲解软件架构。
- **甘特图**：自带 9 个任务和 3 个里程碑，可用于展示项目时间线。任务条、表头、网格、里程碑菱形、图例全部按矢量图元绘制，可继续拖动、改色、改文字。
- **时序图**：以「保存与导出」流程为例，包含 5 条生命线、同步调用、返回调用、自身循环和标注说明文字，适合讲解模块协作。

以上三种工程图除了点按钮载入默认示例，还可在「智能生成 → 图表生成」中用文本 DSL 现场生成并自动排版：甘特图写 `任务: 起始周-结束周`，UML 写 `class 名` 配 `- 属性 / + 方法` 与 `A --> B : 标签`，时序图写 `发起者 -> 接收者: 文字`。周数、行列、网格、生命线位置全部按输入数据自动计算，不是固定坐标。

### 7. 数学函数图像绘制

「函数图像」按钮可输入任意 `y = f(x)` 表达式（每行一个），程序自动构建坐标系、绘制坐标轴、刻度、网格、图例和曲线。支持 `sin / cos / tan / exp / log / sqrt / abs / pi / e` 等常用函数与 `^`、`**` 幂运算，以及 `1e3`、`2.5e-3` 科学计数法。表达式先经 AST 白名单校验（只放行数值运算，拦截属性访问、推导式等，并把 `9**9**9` 这类指数爆炸折算为 NaN，避免卡死），再剔除奇异点（分母为 0、虚数、无穷大）。采样采用「均匀网格 + 自适应二分细化」：峰谷处自动加密，`tan(x)`、`1/x` 的渐近线按符号翻转自动断开，不再出现竖直连线。曲线使用矢量化多段折线生成，可继续选中、改色、改粗细、导出 PNG / SVG。

### 8. 思维导图自动布局

「思维导图」按钮接收缩进式大纲（2 个空格或一个 Tab 为一级，或形如 `1.2.3` 的编号），自动应用 Reingold–Tilford 风格的横向树形布局：后序遍历逐深度测量子树轮廓，再把相邻兄弟子树按各自的实际轮廓「咬合」到一起（而不是按包围盒高度简单堆叠），父节点居中于子节点。这样既保证同一层节点不重叠，又比朴素堆叠排得更紧凑。不同深度自动应用不同的颜色、字号、边框样式，父子节点之间用曲线连接器自动跟随。可生成到当前页面，也可一键生成到新页面。

### 9. 多页画布 / 页面管理

「页面管理」按钮打开页面面板，可在一个工程文件中维护多张图表，每页都有独立的 `Document` 和 `History`。支持新建、复制、重命名、删除、上移、下移以及通过「上一页 / 下一页」快捷切换。当工程包含多个页面时，保存为 `.vcraft.json` 会自动写入工作区格式；打开时会自动识别单页或多页工程，向后兼容旧的单页文件。

## 操作提示

- 左侧选择工具或图元工具，在画布中拖拽即可绘制。
- 左侧「三维」工具可以快速绘制正方体、长方体、球体和三维坐标系。
- 左侧「画笔」工具适合手写批注、勾线和课堂讲解。
- 双击图形可以编辑文本。
- 使用连接工具时，先点击起点图形，再点击终点图形。
- 右侧属性面板可以精确修改坐标、大小、角度、线宽、颜色、线型和连接样式。
- 常用快捷键：`Ctrl+S` 保存，`Ctrl+O` 打开，`Ctrl+Z` 撤销，`Ctrl+Y` 重做，`Ctrl+C` 复制，`Ctrl+V` 粘贴，`Delete` 删除。

## 建议演示流程

1. 启动程序：`python main.py`。
2. 点击「文本生成」，粘贴一段流程描述，生成自动流程图。
3. 拖动几个节点，展示连接线自动跟随。
4. 点击「算法演示」，依次展示 Bresenham、DDA、中点画圆、扫描线填充、线段裁剪和贝塞尔采样。
5. 点击「思维导图」，输入大纲生成横向树状图。
6. 点击「函数图像」，输入 `sin(x)`、`cos(x)`、`0.3*x*sin(x)`，自动绘制坐标系与曲线。
7. 打开「智能识别」复选框，用画笔涂鸦圆、矩形、三角形，观察自动归正效果。
8. 点击「页面管理」，新建一个页面再切回原页面，演示多页工程。
9. 依次载入 UML 类图、甘特图、时序图模板，介绍软件架构与进度。
10. 点击「操作回放」，播放刚才的创作步骤。
11. 最后导出 PNG 或 SVG。
