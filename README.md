# VectorCraft-Py 矢量图形编辑系统

VectorCraft-Py 是一款使用纯 Python 编写的桌面矢量绘图与图表工具。界面基于 Tkinter，位图缓冲与导出基于 Pillow，所有图形基础算法——直线与椭圆光栅化、多边形扫描线填充、贝塞尔采样、线段裁剪、几何变换——全部在项目内从零实现，不依赖任何 CAD 或第三方图形库。

在传统矢量绘图之外，程序还集成了文本生成图表、计算机图形学算法可视化、操作回放、数学函数绘图、手绘形状识别与多页工程管理，既是一款可日常使用的绘图工具，也是一套图形学算法的学习与演示平台。

## 技术栈

- **语言**：Python 3（推荐 3.10 及以上），全程使用类型注解、`dataclass` 领域模型与 `from __future__ import annotations` 延迟注解。
- **图形界面**：Tkinter / `ttk`（clam 主题、自绘双行 Ribbon 工具栏、属性面板、可缩放与平移的画布）。
- **位图与导出**：Pillow（PIL）——项目唯一的第三方依赖，仅作为像素缓冲与 PNG 输出的后端。
- **标准库运用**：
  - `ast` —— 数学表达式安全沙箱（白名单校验 + 节点改写）。
  - `re` —— 流程图 / UML / 甘特图 / 时序图的文本 DSL 解析。
  - `json` —— 工程文件序列化（版本化、向后兼容）。
  - `xml.sax.saxutils` —— 手写 SVG 导出时对文本做转义，防止标记注入。
  - `urllib` / `subprocess` / `hashlib` —— 在线素材搜索、下载与内容寻址缓存。
  - `uuid`、`dataclasses`、`collections`（`deque` / `defaultdict`）、`threading`、`pathlib`、`base64`、`math` 等。
- **总体架构**：Model–View 分离的领域模型；命令 / 备忘录（Memento）式撤销重做；数据驱动的 UI 构建；按图元类型与工具的策略式分发。

## 核心算法实现（全部自研）

所有底层图元都不调用现成的绘图库，而是直接在像素缓冲上实现经典的计算机图形学算法：

- **Bresenham 直线**：整数误差项、全八分支，内层循环零浮点运算；粗线条用圆盘掩膜叠加生成，虚线 / 点线按整数步数取模实现。
- **中点椭圆**：两区域（region 1 / region 2）独立决策参数，逐步增量更新，四象限对称绘制。
- **扫描线多边形填充**：奇偶（even-odd）规则，采用半开区间边判定避免顶点被重复计数，交点排序后成对填充。
- **三次贝塞尔曲线**：同时实现显式 Bernstein 多项式与 de Casteljau 递推两种算法，分别用于实际渲染和算法演示。
- **Cohen–Sutherland 线段裁剪**：四位区域码、快速接受 / 拒绝，再对越界端点做参数化求交。
- **仿射几何变换**：绕任意中心旋转、非均匀缩放（`scale_x` / `scale_y` 直接折入半径与包围盒）、水平 / 垂直镜像。
- **源-over alpha 合成**：实现 Porter–Duff source-over 公式做半透明叠加，半透明描边的柔和边缘即来自 alpha 混合。
- **命中测试**：先用轴对齐包围盒（AABB）快速剔除，再按图元类型分别做多边形射线法 / 椭圆隐式方程精确判定（椭圆边缘留约 15% 容差，便于鼠标拾取）。
- **连接线自动路由**：根据两个图元的相对位置自动推断走线方向，生成直线、正交折线或曲线连接。

## 创新功能

### 1. 文本生成流程图

点击顶部第二行工具栏的「文本生成」，输入箭头式流程描述，程序会自动识别节点、判断分支、连接关系，并生成完整流程图。

示例输入：

```text
开始 -> 接收原始数据 -> 数据完整?
是 -> 清洗与标准化 -> 生成统计图表 -> 保存处理记录 -> 结束
否 -> 生成错误清单 -> 通知用户补充数据 -> 异常结束
```

支持的连接写法包括 `->`、`-->`、`=>`、`→`、`⇒`。判断节点后可以用 `是` / `否` 或 `yes` / `no` 描述分支。

**实现要点**：使用 Kahn 拓扑排序做「最长路径分层」自动计算每个节点所在层级，对含环的图也能容错排版；按关键词启发式推断节点类型（开始/结束→终止符、含 `?` 或「判断」→判定框、输入输出/数据库/文档各有专属样式）；用跨行状态机记住上一个判定节点，把后续以 `是` / `否` 开头的分支正确连接回去；连接线以图元 ID 引用方式存储，路由延迟到渲染层完成。

### 2. 图形学算法演示

点击「算法演示」可打开独立演示窗口。窗口左侧逐帧播放算法过程，右侧显示算法说明，包括核心思想、当前帧含义、关键步骤、公式、复杂度和在本项目中的用途。

当前支持的算法演示：

- Bresenham 直线：展示整数误差项如何决定下一个像素。
- DDA 直线：展示浮点坐标累加与像素取整过程，与 Bresenham 的整数误差形成对照。
- 中点画圆：展示八分对称和中点判别式。
- 扫描线填充：展示多边形交点配对和逐行填充。
- Cohen–Sutherland 裁剪：展示区域码、快速接受 / 拒绝和边界求交。
- 贝塞尔曲线采样：展示控制点和参数采样生成曲线。

演示窗口支持播放 / 暂停、上一步、下一步、重置。

**实现要点**：演示并非播放预录动画，而是真实运行算法并把中间状态（误差项、决策变量 d、扫描线跨度、参数 t 等）逐帧捕获；每帧以一组绘制原语（矩形 / 直线 / 点 / 多边形 / 文本）的轻量 DSL 描述，由演示画布按帧解释绘制；长序列按步幅抽样，兼顾流畅与开销。

### 3. 操作回放时间轴

程序会记录关键编辑步骤，例如绘制图形、移动图形、修改属性、生成流程图、删除、粘贴、对齐和等距分布等。

点击「操作回放」可打开回放窗口，使用播放按钮或时间轴滑块查看创作过程。这个功能可以完整展示作品从空白画布到完整图表的形成过程。回放窗口还提供「导出 GIF」，把整个创作过程保存为动图，便于写进报告或分享。

**实现要点**：每次操作后对文档做一次快照并入环形缓冲（自动跳过与上一帧相同的状态、限制最大帧数）；回放与导出时按 `min` 比例自适应缩放，使任意尺寸的文档都能完整居中显示；GIF 通过 Pillow 的 `save_all` / `append_images` 合成。

### 4. 三维几何辅助绘图

左侧「三维」工具组提供正方体、长方体、球体和三维坐标系。图元支持拖拽绘制、移动、旋转、改色、保存工程，并可导出 PNG / SVG，便于讲解空间几何中的棱、面、球和坐标轴关系。

当三维图元放在三维坐标系内部时，程序会自动给顶点或球心标注三维坐标。

**实现要点**：立方体 / 长方体用单一受限深度偏移伪造斜（cavalier / oblique）投影，背面整体平移 `(+depth, -depth)`，无需任何矩阵运算即可呈现 2.5D 效果，并保持随图元旋转一致；球体由多条经纬向椭圆弧叠加加高光近似。坐标标注则反向求解：用 `scalar_along`（向量点积投影）把每个绘制顶点相对原点的位移分解到三条坐标轴上，回算成 0–5 整数格的 `(x, y, z)`，并对接近整数的值做吸附，让标签显示为整洁的整数坐标。

### 5. 画笔标注与智能形状识别

左侧「画笔」工具可直接在画布上手写或涂画，适合批注、圈重点和临时标记。右上方可调整画笔颜色和粗细。

打开顶部工具栏的「智能识别」复选框后，画笔轨迹结束时会自动调用形状识别算法，把潦草的涂鸦自动归正为矩形、圆 / 椭圆、三角形、菱形或直线。识别结果会替换原始画笔笔迹，实现「随手一画自动变工整图形」的效果。

**实现要点**：识别流水线为「弧长等距重采样 → Douglas–Peucker 折线简化 → 几何顶点分析」。直线用首尾直线距离 / 轨迹总长的「平直度」比值判定；圆 / 椭圆利用「椭圆上点满足 `((x-cx)/rx)² + ((y-cy)/ry)² = 1`」的代数恒等式，对归一化半径做均值 + 方差检验；四边形通过顶点落在「角点簇」还是「中线附近」来区分矩形与菱形。所有阈值都按包围盒对角线 / 宽高的比例自适应，因此对大小不同的笔迹都稳健，并能容忍多描一笔的过描情况。

### 6. UML 类图 / 甘特图 / 时序图模板

在顶部工具栏「模板与演示」一栏提供三个工程类模板：

- **UML 类图**：展示 Shape、Style、Document、Page、History、Renderer 等核心类的属性、方法、聚合 / 组合 / 依赖关系。
- **甘特图**：自带任务和里程碑，任务条、表头、网格、里程碑菱形、图例全部按矢量图元绘制，可继续拖动、改色、改文字。
- **时序图**：以「保存与导出」流程为例，包含多条生命线、同步调用、返回调用、自身循环和标注说明文字。

以上三种工程图除了点按钮载入默认示例，还可在「智能生成 → 图表生成」中用文本 DSL 现场生成并自动排版：甘特图写 `任务: 起始周-结束周`，UML 写 `class 名` 配 `- 属性 / + 方法` 与 `A --> B : 标签`，时序图写 `发起者 -> 接收者: 文字`。

**实现要点**：DSL 全部基于正则 + 首字符分派解析，再转换成与编程接口共用的同一套规格，因此「文本输入」与「代码生成」复用同一个布局引擎。布局完全数据驱动而非固定坐标：UML 列数按 `ceil(sqrt(类数))` 自动推导、行高取每行最高的类盒；甘特图周数、列宽、网格、里程碑位置全部由数据计算；时序图按参与者数量均分横向位置、按消息序号累加纵向行。连接线均以图元 ID 引用，端点移动后自动重新走线。

### 7. 数学函数图像绘制

「函数图像」按钮可输入任意 `y = f(x)` 表达式（每行一个），程序自动构建坐标系、绘制坐标轴、刻度、网格、图例和曲线。支持 `sin / cos / tan / exp / log / sqrt / abs / pi / e` 等常用函数与 `^`、`**` 幂运算，以及 `1e3`、`2.5e-3` 科学计数法。

**实现要点**：

- **安全沙箱**：表达式先经 `ast` 白名单校验（deny-by-default，只放行数值运算、白名单函数与变量 `x`，拦截属性访问、下标、lambda、推导式与关键字参数），再在 `__builtins__` 置空的命名空间中求值。
- **DoS 防护**：在 AST 层把 `**` 改写为受限的 `_safe_pow`，使 `9**9**9` 这类指数爆炸永远不会真正展开成巨大整数，而是折算为 NaN，避免卡死。
- **预处理**：自动插入隐式乘法（如 `2x` → `2*x`），并用占位符保护科学计数法，避免 `1e3` 被误拆成 `1*e3`。
- **自适应采样**：先均匀网格采样，再按「中点与弦中点偏差」递归二分细化，峰谷处自动加密，并设全局细分预算上限。
- **渐近线处理**：以相邻点差分的「中位数 × 60」作为稳健阈值检测跳变，在 `tan(x)`、`1/x` 的渐近线处插入断点，曲线自然断开而不再出现竖直连线。

曲线、坐标轴、刻度全部以本程序自身的矢量图元生成，可继续选中、改色、改粗细、导出 PNG / SVG。

### 8. 思维导图自动布局

「思维导图」按钮接收缩进式大纲（2 个空格或一个 Tab 为一级，或形如 `1.2.3` 的编号），自动应用 Reingold–Tilford 风格的横向树形布局。不同深度自动应用不同的颜色、字号、边框样式，父子节点之间用曲线连接器自动跟随。可生成到当前页面，也可一键生成到新页面。

**实现要点**：采用真正的 Reingold–Tilford「轮廓合并」算法——后序遍历逐深度测量子树的上 / 下轮廓，再把相邻兄弟子树按各自的实际轮廓「咬合」到一起（而不是按包围盒高度简单堆叠），父节点居中于子节点，从而既保证同层不重叠又排得更紧凑。节点宽度用 CJK 感知度量（非 ASCII 字符按 1.7 倍宽计）；当某一层子节点过多时，自动拆分为分组列，避免出现极端高的单列；大纲跳级时还会自动补入占位节点保持结构完整。

### 9. 多页画布 / 页面管理

「页面管理」按钮打开页面面板，可在一个工程文件中维护多张图表，每页都有独立的 `Document` 和 `History`。支持新建、复制、重命名、删除、上移、下移以及通过「上一页 / 下一页」快捷切换。

**实现要点**：工程文件采用版本化、自描述的 JSON 格式（单页为 1.0，多页工作区为 1.1 并带 `kind` 区分），读取时能把旧的单页文件透明升级为单页工作区，做到向后兼容；每个页面携带各自独立的撤销 / 重做历史，切换页面时自动同步保存与恢复。

### 10. 在线素材搜索与插入

支持在程序内按关键词搜索网络图形素材（来源包括 Bing 图片与 Wikimedia Commons），预览缩略图后一键插入画布，并随工程一起保存 / 导出。

**实现要点**：内置中英双语查询扩展（如「流程图」→ flowchart、「电路」→ circuit diagram）并按是否含中文调整搜索源优先级；下载具备字节上限保护、`urllib` 失败时回退到 `curl` 子进程，适配受限网络；素材按 `sha256(内容 + URL)` 做内容寻址磁盘缓存，避免重复下载；SVG 自动栅格化为 PNG 缩略图，并按是否含透明通道选择 PNG / JPEG 重编码。插入的位图在导出 SVG 时以 `data:` Base64 URI 内嵌。

## 项目结构

| 模块 | 职责 |
| --- | --- |
| `vectorcraft/app.py` | 主窗口、Ribbon 工具栏、事件与工具分发、撤销重做、回放、页面管理 |
| `vectorcraft/model.py` | `Shape` / `Style` / `Document` / `Connection` 领域模型与 JSON 序列化 |
| `vectorcraft/renderer.py` | 自研软件光栅器（Bresenham / 中点椭圆 / 扫描线填充 / 贝塞尔 / alpha 合成） |
| `vectorcraft/geometry.py` | 2D 向量数学、旋转、命中测试、Cohen–Sutherland 裁剪、连接线路由 |
| `vectorcraft/storage.py` | 工程文件读写、PNG / SVG 导出、向后兼容加载 |
| `vectorcraft/auto_flow.py` | 文本 → 流程图（拓扑分层、节点类型推断、分支跟踪） |
| `vectorcraft/mind_map.py` | 文本 → 思维导图（Reingold–Tilford 轮廓合并布局） |
| `vectorcraft/templates.py` | UML / 甘特 / 时序图模板与 DSL 解析、数据驱动布局 |
| `vectorcraft/function_plot.py` | 数学函数绘图（AST 沙箱、自适应采样、渐近线处理） |
| `vectorcraft/shape_recognizer.py` | 手绘形状识别（重采样 + Douglas–Peucker + 几何分析） |
| `vectorcraft/three_d.py` | 2.5D 立体图元投影与三维坐标标注 |
| `vectorcraft/algorithm_steps.py` | 图形学算法分帧与说明文本生成 |
| `vectorcraft/online_assets.py` | 在线素材搜索、下载与内容寻址缓存 |
| `vectorcraft/history.py` | 基于文档快照的撤销 / 重做栈 |

## 操作提示

- 左侧选择工具或图元工具，在画布中拖拽即可绘制。
- 左侧「三维」工具可以快速绘制正方体、长方体、球体和三维坐标系。
- 左侧「画笔」工具适合手写批注、勾线和临时标记。
- 双击图形可以编辑文本。
- 使用连接工具时，先点击起点图形，再点击终点图形。
- 右侧属性面板可以精确修改坐标、大小、角度、线宽、颜色、线型和连接样式。
- 常用快捷键：`Ctrl+S` 保存，`Ctrl+O` 打开，`Ctrl+Z` 撤销，`Ctrl+Y` 重做，`Ctrl+C` 复制，`Ctrl+V` 粘贴，`Delete` 删除。

## 推荐体验流程

1. 启动程序：`python main.py`。
2. 点击「文本生成」，粘贴一段流程描述，生成自动流程图。
3. 拖动几个节点，观察连接线自动跟随。
4. 点击「算法演示」，依次查看 Bresenham、DDA、中点画圆、扫描线填充、线段裁剪和贝塞尔采样。
5. 点击「思维导图」，输入大纲生成横向树状图。
6. 点击「函数图像」，输入 `sin(x)`、`cos(x)`、`0.3*x*sin(x)`，观察自动绘制的坐标系与曲线。
7. 打开「智能识别」复选框，用画笔涂鸦圆、矩形、三角形，观察自动归正效果。
8. 点击「页面管理」，新建一个页面再切回原页面，体验多页工程。
9. 依次载入 UML 类图、甘特图、时序图模板。
10. 点击「操作回放」，播放刚才的创作步骤，并可导出 GIF。
11. 最后导出 PNG 或 SVG。
